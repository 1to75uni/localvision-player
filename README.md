# LocalVision Player 1.9.3 — 좌우 전용 대기 이미지

사용자가 제공한 가로 이미지 IMG_9381.jpeg는 왼쪽, 세로 이미지 IMG_9380.jpeg는 오른쪽 대기 화면에 적용한 전체 Player 패키지입니다. 두 이미지 원본 바이트를 그대로 포함합니다.

영상 파일을 준비하고 재생을 시작하는 동안 각 칸의 대기 이미지가 보입니다. 재생 시작과 현재 프레임 데이터 또는 실제 진행이 확인되면 영상이 표시됩니다. 대기 이미지는 비율을 유지하며 전체가 보이도록 배치하고 남는 여백은 흰색으로 표시합니다. 영상 자체의 표시 비율은 기존 설정을 유지합니다.

CMS 2.1.0은 그대로 사용합니다. ZIP 최상위 폴더 안의 모든 파일을 기존 Player 저장소 루트에 반영하세요. waiting-left.jpg와 waiting-right.jpg도 필수 파일입니다.
