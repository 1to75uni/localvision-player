# LocalVision Player 1.9.1

페이지 캐시에서 리디렉션 이력이 있는 HTML을 반환하여 화면 로딩이 실패할 수 있는 1.9.0의 결함을 수정합니다. 파일 원본 대조, 검증 후 목록 적용, 좌우 독립 재생 및 이전 목록 복원 기능을 포함한 전체 Player 패키지입니다.

현재 CMS가 2.1.0이면 이번에는 Player만 업데이트합니다. **DEPLOY_AND_OPERATIONS_KO.md**의 배포·기기 확인 순서와 **TEST_REPORT.md**의 시험 범위를 확인하세요. 기존 미디어 캐시와 매장 설정을 지우지 않습니다.

ZIP 최상위 폴더 안 내용물 전체를 기존 Player 저장소 루트에 반영합니다. `_headers`, `sw.js`, `index.html` 및 모든 스크립트를 함께 배포합니다. 운영 서버/깃허브에 자동 배포하는 패키지가 아닙니다.

실제 장애 기기의 WebView·네트워크 로그는 아직 확보하지 못했습니다. 자동 시험 통과는 모든 장비에서 문제없이 작동한다는 인증이 아닙니다.
