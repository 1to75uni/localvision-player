# Player 1.9.6 시험 결과

전체 자동 회귀시험: **92개 통과 / 실패 0개 / 건너뜀 0개**.
환경: Node 24.19.0, 가상 DOM·시계·미디어, 메모리 CacheStorage. 실제 HTTP Response/Headers 파싱을 사용했습니다.
원문: verification/current-tests.tap. 재현 명령: `node --test --test-concurrency=1 --test-reporter=tap tests/*.test.cjs`.

이번 수정의 핵심 오류 주입 시험은 다음을 확인합니다.

- JSON, HTML, 텍스트 D1 한도 응답의 HTTP 상태·경로·Retry-After 보존.
- Workers Error 1027 구분, 원인 불명 HTML을 D1으로 잘못 판정하지 않음.
- 200 HTML, null, 배열, 문자열, 잘린 응답 본문 처리.
- 정상 응답에 과거 D1 오류 로그가 있어도 현재 장애로 오판하지 않음.
- HTTP 404일 때 기존 CMS 호환 경로로만 우회.
- 캐시가 없는 시작에서 좌우 대기 이미지와 공통 대기 적용.
- 서버 복구·네트워크 복구 후 자동 재생, 강제 새로고침 없음.
- 장애 대기가 재시작 후에도 유지되며 저장된 좌우 영상 재생.
- 같은 재생목록의 정상 응답에서도 이전 오류 화면 제거, 양쪽 재생 세대 유지.
- 첫 부팅 시 경로별 일일 예산이 이미 소진되어 있어도 대기 화면 유지, 예산 초기화 없음.
- 콘텐츠가 실제로 비어 있으면 설정 오류 안내 유지.

기존 좌우 독립 재생·디코더 회수, 영상 전 대기 사진, 파일 무결성, 저장 저널, 오프라인 복구, 서비스워커, FREE 100 요청 예산 시험도 함께 통과했습니다.

CMS 2.1.2와 free-budget.js는 이번 변경에서 수정하지 않았습니다. 기존 FREE 100 계산과 제한이 그대로 적용됩니다. CMS 40개 시험 및 100대 쓰기 계산은 이전 2.1.2 배포 검증이며 이번 Player 시험 결과와 구분합니다.

실제 TV/APK, 운영 Cloudflare 계정, 실제 할당량 소진/과금 측정은 실행하지 않았습니다. 로컬에 영상이 없거나 캐시가 손상되면 광고 재생을 보장하지 않습니다. 서버가 복구되기 전에는 새 편성 반영·상태 보고가 지연될 수 있습니다.
