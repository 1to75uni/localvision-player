# LocalVision Player 1.9.6 — API 복구 수정본

CMS 연결 실패 때 큰 오류 화면에 멈추는 문제를 수정한 전체 Player 소스입니다. CMS 2.1.2 FREE 100과 함께 사용합니다. 이번 변경은 Player에만 적용되므로 CMS 2.1.2를 이미 배포했다면 CMS를 다시 배포할 필요는 없습니다.

- 서버가 JSON 대신 HTML/텍스트를 보내도 HTTP 상태와 오류 종류를 보존합니다.
- 확인된 D1 한도 오류, Workers 요청 한도 오류, 일반 서버 오류를 구분합니다. 확인할 수 없는 원인을 D1이라고 단정하지 않습니다.
- 정상 저장된 영상이 있으면 재생을 유지합니다. 없으면 좌우 전용 대기 사진을 표시하고 재연결합니다.
- 정상 응답이 돌아오면 플레이리스트를 준비·검증한 후 자동 재생합니다. 동일 재생목록 복구 때 남던 오류 덮개도 닫습니다.
- 기존 FREE 100 요청 예산, 상태 저장 간격, 미디어 캐시와 좌우 대기 사진을 유지합니다.

적용: 이 폴더 안 파일 전체를 기존 Player 저장소 루트에 반영하고 기존 Pages 설정으로 배포합니다. 새 api-response.js도 반드시 포함해야 합니다. 배포 뒤 플레이어를 한 번 다시 열고 /version.json에서 v1.9.6-api-recovery를 확인하세요. 미디어 캐시와 사이트 데이터는 삭제하지 마세요.
